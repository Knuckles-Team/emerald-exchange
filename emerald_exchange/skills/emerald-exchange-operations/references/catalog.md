# Provider workflow catalog

Load only the workflow relevant to the current request.

- [emerald-exchange-kg-ingestion](../../emerald-exchange-kg-ingestion/WORKFLOW.md): Natively ingest live Emerald Exchange trading state into the medulla knowledge graph as typed OWL nodes — :Portfolio, :Position, :Instrument, :Quote, and :MarketBar (OHLCV timeseries) — via the emerald_ingest_snapshot MCP tool. Use when the agent must snapshot the current account, open positions, and optionally quotes/history for given symbols into the KG so they become queryable/linked knowledge. Do NOT use for one-off reads that shouldn't be persisted (use emerald-exchange-market-data) or to place orders (use emerald-exchange-order-execution).
- [emerald-exchange-market-data](../../emerald-exchange-market-data/WORKFLOW.md): Read market data and account state through the emerald-exchange MCP server — quotes, OHLCV history, stock bars, news and dividends, company and multi-asset records, the available exchange backends, account and positions — via the typed emerald_exchange_* read tools (not raw exchange SDK calls). Use when the agent must fetch a live quote for a symbol, pull historical bars for backtesting or analysis, list which exchange backends are wired, or read account equity and positions. Do NOT use to place or cancel orders (use emerald-exchange-order-execution) or to push records into the knowledge graph (use emerald-exchange-kg-ingestion).
- [emerald-exchange-market-research](../../emerald-exchange-market-research/WORKFLOW.md): Research markets through the emerald-exchange MCP server — crypto funding, whale and on-chain data, arbitrage scans and cointegration, prediction-market orderbooks and ensemble-forecast arbitrage, SEC filings and fundamentals with a forensic screen, and prediction-market wallet intelligence — one typed tool per operation (emerald_crypto_*, emerald_prediction_markets_*, emerald_fundamentals_*, emerald_wallet_intel_*). Use when the agent must gather research inputs before an analysis or a trade. Every tool reads; none places an order (use emerald-exchange-order-execution).
- [emerald-exchange-order-execution](../../emerald-exchange-order-execution/WORKFLOW.md): Place, cancel, and check trading orders through the emerald-exchange MCP server with mandatory pre-trade risk validation, plus the emergency halt/resume kill switch and the risk checks and Kelly sizing that gate an order — one typed tool per operation (emerald_orders_submit, emerald_orders_cancel, emerald_orders_status, emerald_orders_halt, emerald_orders_resume, emerald_risk_*). Use when the agent must size and submit a market/limit order, cancel or status an existing order by id, check drawdown or daily loss, or halt all trading. Do NOT use to read quotes or positions (use emerald-exchange-market-data), and be deliberate in live mode — paper is the default. Do NOT bypass the risk guard with raw backend calls.
- [emerald-exchange-quant-analysis](../../emerald-exchange-quant-analysis/WORKFLOW.md): Run quantitative analyses through the emerald-exchange MCP server — signal regime, fusion and surveillance, strategy backtests, OU stat-arb bands and dynamic hedge beta, SABR volatility surfaces, market-making quotes and backtest validation, and the bull/bear trading debate — one typed tool per analysis (emerald_signals_*, emerald_strategy_*, emerald_statarb_*, emerald_derivatives_*, emerald_market_making_*, emerald_debate_*). Use when the agent must measure a signal, validate a strategy, price volatility, or argue a trade before it is sized. Every analysis is decision-only and never places an order; to trade use emerald-exchange-order-execution.
