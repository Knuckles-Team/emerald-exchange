# EMERALD-MEDIA requirements

Every requirement this specification owns, with the proof that closes it. Delivery state and
public evidence for each ID are recorded in [`status.json`](status.json); this file defines what
each ID means. The design is in [`spec.md`](spec.md) and [`plan.md`](plan.md), the test contract
in [`test-spec.md`](test-spec.md), and the work order in [`tasks.md`](tasks.md).

| ID | Requirement | Verification |
|---|---|---|
| `EMERALD-MEDIA-R001` | **Finance media intake into reviewable Emerald skills.** Stage: content intake and a recommendation guard. Caller for intake: an agent run of the `media-watch` tool writes `emerald_exchange/skills/<skill>/capture_log.json`. The skill provider (`emerald_exchange/skills/__init__.py`) then serves it as `skill://` content (CONN-EMERALD-EXCHANGE-CONNECTOR-CONTENT-R001). Caller for the guard: `emerald_exchange/mcp/mcp_strategy.py::emerald_strategy` → `emerald_exchange/strategy_links.py::require_mapped_strategy` → the medulla recommendation of EG-FINANCE-PRIMITIVES-R009. Rule: the designated sources are the five public URLs in `specs/finance-media-intake/spec.md`. Each capture records URL, capture time and caption language `en`, requested explicitly and never as a wildcard. It also records the media, caption and frame state. Each skill labels every statement `source_demonstrated`, `source_claim`, `editor_inference` or `verified`. Each mechanical trading rule carries a `StrategySpec` stable ID and version, or the value `UNMAPPED`. `require_mapped_strategy` refuses an `UNMAPPED` rule with `STRATEGY_UNMAPPED`, and a rule without a sealed `BacktestRun` (EG-FINANCE-PRIMITIVES-R008) with `STRATEGY_UNVALIDATED`. Missing captions or frames stay visible; nothing fills the gap. Writes: none. Depends on: EG-FINANCE-PRIMITIVES-R007, R008, R009. | Test: `tests/test_media_intake_contract.py::test_unmapped_rule_cannot_drive_recommendation` (L3) drives `emerald_strategy` with a fixture. `::test_capture_log_separates_source_and_claim` (L2) reads `tests/fixtures/media/capture_log.json`. |
