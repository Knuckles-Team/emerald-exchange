# EMERALD-OPS — Requirements

Every requirement this specification owns, with the proof that closes it. Delivery state and
public evidence for each ID are recorded in [`status.json`](status.json); this file defines what
each ID means. The design is in [`spec.md`](spec.md) and [`plan.md`](plan.md), the test contract
in [`test-spec.md`](test-spec.md), and the work order in [`tasks.md`](tasks.md).

|---|---|---|
| `EMERALD-OPS-R001` | **Read-only exchange operations are per-operation tools.** Stage: served MCP tools. Entry: `tools/call` on `emerald_exchange_get_quote`, `_get_historical`, `_get_positions`, `_get_account`, `_get_order_status` and `_exchanges`. Caller: `emerald_exchange/mcp_server.py::get_mcp_instance` → `register_tool_surface` with `verbose_targets` → `emerald_exchange/exchange_operations.py::ExchangeReadOperations` → the active `ExchangeBackend` method (the venue call). Each read is one typed tool. No write operation is served unguarded: submit, cancel, connect and disconnect exist only behind `RiskGuard` in `emerald_orders`. Emerald computes nothing here; every calculation is medulla's through `scion_sdk.compute`. Arbora reads markets, events and orders through nine further per-operation tools (EMERALD-OPS-R005). Refusals: `provider_unavailable` without the provider message. Writes: none. Depends on: none. Caller chain: console script emerald-exchange-mcp (pyproject.toml project.scripts) -> emerald_exchange/mcp_server.py::mcp_server -> get_mcp_instance -> scion_sdk.mcp.tool_surface.register_tool_surface(verbose_targets=ExchangeReadOperations) at mcp_server.py:131 -> emerald_exchange/exchange_operations.py::ExchangeReadOperations -> ExchangeBackend method in emerald_exchange/backends.py. Shape: ExchangeReadOperations wraps one ExchangeBackend and exposes only read methods, listed in READ_OPERATIONS; register_tool_surface turns each public method into an emerald_exchange_<name> tool with prefix emerald; order writes stay in mcp_orders.py::register_order_tools. | Test: `tests/test_order_guard.py::test_per_operation_surface_is_read_only` (L3) lists the served tools. `test_no_unguarded_order_tool_is_served` asserts that no write tool is registered. |
